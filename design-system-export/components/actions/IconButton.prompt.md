Round icon-only button for toolbars, close actions, calendar navigation and notification bells.

```jsx
<IconButton icon={<Icon name="bell"/>} label="Notificações" variant="secondary" badge={3}/>
<IconButton icon={<Icon name="chevron-left"/>} label="Dia anterior"/>
```

- variants ghost / secondary / primary / tint / onBrand
- sizes sm 32, md 40, lg 48 (use lg for primary mobile actions)
