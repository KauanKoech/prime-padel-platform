Labelled text field for booking checkout, admin forms and search.

```jsx
<Input label="WhatsApp" placeholder="(11) 90000-0000" iconLeft={<Icon name="phone" size={18}/>} hint="Enviamos a confirmação por aqui"/>
<Input label="E-mail" error="Informe um e-mail válido"/>
```

- `size="sm"` (40px) for dense admin toolbars
- `multiline` renders a textarea
- `optional` adds "(opcional)"
