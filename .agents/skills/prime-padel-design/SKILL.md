# Prime Padel Design

Antes de agir:

1. Leia `../../../DESIGN.md`.
2. Leia `../../../design-system-export/SKILL.md` por completo.
3. Leia `../../../design-system-export/readme.md` por completo.
4. Consulte somente tokens, componentes, guidelines e UI kits relacionados a tarefa atual.

Trate `design-system-export/` como fonte canonica de referencia. Para codigo de producao, adapte somente o necessario para o framework e mantenha os componentes sob controle da aplicacao.

Preserve estas restricoes:

- Use portugues brasileiro, com voz calorosa e direta.
- Construa mobile-first e valide teclado, foco, contraste e movimento reduzido.
- Nao invente fatos, depoimentos, eventos, politicas ou estrutura da arena.
- Nao apresente referencias visuais de terceiros como ativos da Prime Padel.
- Nao use `_ds_bundle.js` como dependencia de runtime da aplicacao final.
- Registre divergencias intencionais em `../../../docs/DECISIONS.md`.
